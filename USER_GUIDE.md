## Understanding Tokens

### What Are Tokens?

Tokens are the currency used on TACBAY for bidding on auctions. Think of them as credits that allow you to participate in auctions.

### Token Balance

Your current token balance is always visible in the header when you're logged in, displayed with a coin icon.

### How Tokens Work

- **Placing a Bid**: Tokens are deducted from your balance when you place a bid
- **Getting Outbid**: If someone outbids you, your tokens are automatically refunded
- **Winning an Auction**: When you win, the tokens remain with the seller
- **Free Tokens**: New users receive 100 tokens upon signup

### Token Refund System

The automatic refund system ensures fairness:
- When you place a bid, tokens are held
- If someone bids higher, your tokens are immediately returned
- You only lose tokens when you win an auction

## Creating Auction Listings

### How to Create a Listing

1. Navigate to the marketplace homepage
2. Scroll to the **"List Your Item"** section
3. Fill in the listing form:

**Required Fields:**
- **Product Title**: Short, descriptive name for your item

**Optional Fields:**
- **Product Description**: Detailed description of the item
- **Starting Bid**: Minimum token amount to start bidding (defaults to system minimum)
- **Auction Start**: Scheduled start time for the auction
- **Auction End**: Automatic closing time for the auction

4. Click **"Create Listing"** to publish

### Listing Best Practices

- Use clear, descriptive titles
- Provide detailed descriptions to attract bidders
- Set reasonable starting prices
- Consider setting an end time to create urgency
- Include condition, specifications, and other relevant details

### Listing Status

Auctions can have two statuses:
- **OPEN**: Accepting bids
- **CLOSED**: No longer accepting bids

## Placing Bids

### How to Bid on an Auction

1. Navigate to the auction detail page
2. Review the current bid and minimum bid requirement
3. Enter your bid amount (must be at least 1 token higher than current bid)
4. Click **"Place Bid"**

### Bidding Rules

- You must be logged in to place bids
- Bids must exceed the current price by at least 1 token
- You must have sufficient tokens in your balance
- Bids on closed auctions are not allowed
- Once placed, bids cannot be retracted

### Minimum Bid Requirements

The minimum bid is always:
- Current price + 1 token (if there are existing bids)
- Starting price + 1 token (if no bids exist)

### Real-Time Updates

The auction page updates in real-time, so you can:
- See new bids as they come in
- Watch the countdown timer
- Monitor your position in the bid history

### Bid History

View complete bid history including:
- Bid amounts
- Bidder usernames
- Timestamp of each bid
- Latest bids appear at the top

## Troubleshooting & FAQ

### Common Issues

**Q: I can't place a bid. Why?**
- Ensure you're logged in
- Check that the auction is OPEN
- Verify you have enough tokens
- Make sure your bid meets the minimum requirement

**Q: Where did my tokens go?**
- Check if you placed a bid (tokens are held during active bids)
- If outbid, tokens should be automatically refunded
- View your token balance in the header

**Q: I don't see my listing**
- Check the "My Listings" page
- Verify you're logged in as the correct user
- Try refreshing the page

**Q: Messages aren't sending**
- Check your internet connection
- Ensure you're logged in
- Try refreshing the page

**Q: The countdown timer isn't showing**
- This is normal for auctions without an end time
- Only auctions with set end times display countdowns

### When Do Tokens Get Refunded?

Tokens are automatically refunded when:
- Someone places a higher bid than yours
- An auction is cancelled
- Your bid is otherwise superseded

Tokens are NOT refunded when:
- You win the auction
- You use them for other purposes

### How Do I Know If I Won?

- Check the "My Bids" page for auction status
- If you're the highest bidder when the auction closes, you win
- Auctions without end times may require seller action to close

### Auction Timing

- **No End Time**: Seller decides when to close
- **With End Time**: Automatically closes at specified time
- **Start Time**: Auction won't accept bids until start time
